# Trainings-App – Ideen-Backlog

Sammelstelle für alle Ideen außerhalb des aktuellen Umfangs. Nichts geht verloren, nichts wird ungeplant gebaut.

**So funktioniert's**
- Neue Idee: im Chat „Idee: …“ schreiben → Claude trägt sie unten ein (oder direkt selbst eintragen).
- Prio: **muss** / **soll** / **Spielerei**
- Status: **neu** → **geprüft** → **geplant (Vx)** → **erledigt** · oder **verworfen** (mit Grund, bleibt stehen)
- Bei jedem Meilensteinstart wird der Backlog durchgesehen und entschieden, was in die nächste Version kommt.
